# FitCoach — case study

**Type:** Independent portfolio demo, not a commercial commission.
**Stack:** Next.js, React, TypeScript, Tailwind CSS, Node.js.
**Workflow:** Developed with substantial Codex assistance. Personal contributions should be described separately by the portfolio owner; this project is not evidence of prior paid client work.

## Brief

Design a warm, approachable personal-training website that helps a visitor compare programmes and try a simple enquiry flow. Make it work on a narrow phone screen as well as a desktop, with clear feedback and no misleading claims.

## Solution

An editorial landing page combines original illustration, a sample weekly rhythm, three transparent example programmes and a short FAQ. Selecting a programme carries the choice into the form. Shared validation provides immediate feedback and protects the server endpoint. A local receipt confirms persistence without pretending an email or real booking was made.

## Deliverables

Responsive page, original vector artwork, local enquiry API, automated tests, English documentation and screenshots. The project uses no paid APIs or external assets.

## What this demonstrates

Turning a bounded brief into a coherent interface; responsive layout; interactive state; validating user input; error recovery; and distinguishing demo behaviour from production requirements.

## Honest limitations

No real clients, conversion measurements, coaching credentials or commercial results. No live email delivery, payments, authentication or hosted database. Public deployment is a separate task and requires approval.

## Short portfolio description

FitCoach is a personal-training website concept built with Next.js and TypeScript. It includes responsive programme comparison, a mobile menu and a locally persisted demo enquiry form with validation and retry handling. Built as a personal project with substantial AI assistance; not a client commission.
